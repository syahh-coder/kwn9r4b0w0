# ADR-001: GenAI-assisted evidence-based verification

- Date: 2026-10-24
- Status: Accepted; implementasi lokal terintegrasi, bukti/status terkini di TASKS.md. Deployment terpisah.

## Context
Keyword-only matching cannot robustly handle user paraphrases. Training custom ML is too heavy for a small course website. Need automatic *draft* analysis and report.

## Decision
Next.js + TypeScript backend; Gemini API for extraction/analysis with evidence retrieved from approved external providers; Supabase Auth/Postgres for admin and reports. `unverified` when evidence inadequate. Human reviews before publish.

## Alternative rejected
- Keyword whitelist as truth classifier (insufficient).
- AI-only truth judgments with no cited sources (untrustworthy).
- Fully automatic publication (high reputational risk).

## Risks
Gemini free-tier quotas and privacy, provider availability, factual errors, scraping permissions, API abuse. See security docs and recheck provider pricing prior to enabling billing.
